# ProgramacionII-Tarea04-NeilsSandoval

Nombre de la aplicacion: Dashboard de estudiante

Descripcion:
Es una plataforma que sirve a los estudiantes para llevar un control de sus tareas y proyectos,
esta aplicacion permite añadir, eliminar y marcar tareas pendientes para llevar un control ordenado de entregas y nuevas tareas

Tecnologias utilizadas:
React Native
Expo
TypeScript
React Navigation
React Hooks

Instrucciones basicas para ejecutar aplicacion:
Clonar el repositorio y entrar a la carpeta
Instalar dependencias del proyecto (npm install)
Iniciar servidor (npx expo start)
sigue las instrucciones segun el dispositivo utilizado
